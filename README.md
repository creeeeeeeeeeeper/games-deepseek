# 🎮 小游戏大全 · 100 款手搓 HTML 小游戏

一个纯前端的小游戏集合网站。首页以**封面图卡片**收录 **7 大分类、共 100 款**小游戏，**全部 100 款均已实现为可玩页面**；每款游戏 = `index.html` + `style.css` + `script.js` 三张独立图纸（互不合并）。对战/双人类游戏内置「单人·对战 AI / 双人·同屏」切换。纯原生 JavaScript，零第三方依赖、无需构建，双击 `index.html` 即可离线游玩。

## 界面风格（v3 · 街机印刷海报 · 深色车间版）

按"反主流"设计规则重构：错位套印标题、印刷噪点与网纹半调、打孔票式分类签、不对称版面（目录边条 + 藏品架）、硬阴影墨块按钮、非线性的"印刷吸附/回弹"动效。明确**不使用**紫/靛/蓝紫渐变、纯平底色、Tailwind 默认色板、emoji 功能图标、ease-in-out 线性动画。
- 功能图标使用**本地化 Iconify SVG**（`assets/icons/`），不依赖任何 CDN；
- 卡片封面仍支持 `assets/covers/<slug>.png` 真实截图（放入即自动替换占位封面）；
- 100 个游戏页共用外壳 `assets/game.css`（类名与 CSS 变量契约保持不变，便于各游戏 style.css 叠加）。

## 目录结构

```
GAMES/
├── index.html            # 收录首页（印刷海报式：检索台 + 分类签 + 藏品架）
├── assets/
│   ├── index.css         # 首页样式 v3（噪点/套印/半调全部 CSS+SVG 自绘）
│   ├── index.js          # 首页渲染逻辑 + 100 款游戏数据（built 全为 true）
│   ├── covers/           # 卡片封面截图（可选，放入即自动展示）
│   ├── icons/            # 本地 Iconify SVG（search/x/refresh/arrow…，离线可用）
│   └── game.css          # 100 个游戏页共享外壳样式 v3
├── PROGRESS.md           # 收录进度与批次记录
└── games/
    ├── 2048/
    │   ├── index.html    # 游戏页面
    │   ├── style.css     # 该游戏专属样式
    │   └── script.js     # 该游戏逻辑
    └── ...（共 100 个游戏目录）
```

## 如何打开

直接用浏览器打开 `index.html` 即可，或使用任意静态服务器：

```bash
python -m http.server 8000   # 然后访问 http://localhost:8000
```

## 单双人模式切换（对战/双人类游戏）

分段控件位于游戏页顶部：🤖 单人·对战AI / 👥 双人·同屏轮流（或同屏双打）。
AI 模式由内置简单 AI 自动决策；双人模式两位玩家同屏轮流 / 分键 / 传屏操作，无需联网。

## 卡片封面

每张卡片 = **封面图 + 游戏名 + 简介**。截图按 `assets/covers/<slug>.png` 命名放入后，首页自动用真实截图替换生成的渐变色占位封面，无需改代码。

## 约定

- 每个游戏目录包含 `index.html` / `style.css` / `script.js` 三个独立文件，页面复用 `assets/game.css` 外壳（返回按钮、标题、HUD、按钮、模态框、配色变量），游戏自身样式叠加在 `style.css`。
- 首页 HTML / CSS / JS 同样分离：`index.html` + `assets/index.css` + `assets/index.js`。
- 全部原生 JavaScript，无第三方依赖；动画采用 CSS keyframes / transition 与 Canvas rAF。
